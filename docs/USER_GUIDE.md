# openCare: onboarding a new client

1. **Admin → Clients → Add a client.** Enter the manufacturer's name. The subdomain fills itself in;
   add their domain now or later.
2. **Edit site** opens automatically. Fill in, top to bottom:
   - Logo, main + accent colour, heading style
   - Home page title, intro text and a wide hero photo
   - About text, key numbers, who they serve, FAQs
   - Currency and whether to show prices (turn off for "price on request" clients)
   - Whether to show the *Become a Distributor* page
   - Leave contact fields empty so leads come to your openCare WhatsApp/email
   - Click **Save changes** (bottom bar), then **Preview site ↗**
3. **Manage products →** switches the catalogue screens to this client.
   Add categories first if they have several product types, then products
   (name + description are the only required fields).
4. **Connect their domain** — follow the yellow box on the client page, or
   [DEPLOYMENT.md](DEPLOYMENT.md#4-a-clients-own-domain).

## Handling leads

- New leads are emailed to you with the client name in the subject: `[Acme Paints] Product enquiry: …`
- **Admin → Leads** shows everything. Click a lead to:
  - call/WhatsApp the customer,
  - **Copy details to forward** to the manufacturer,
  - set status *contacted → forwarded → closed* and add notes.
- Filter by client to see how each manufacturer's site is performing.
